# Luma Merge (HTML5 – Phone Friendly)

**A Tallgrass Signal Studios game.**

Two modes in one app that feel like separate games:

## Infinite Mode
- Endless run
- Difficulty rises the longer you play
- Board fills faster at higher difficulty
- Lives system – board full or bad play costs lives
- Big celebration rewards and bonus Lumens
- Goal: survive and push as far as possible

## Campaign Mode
- Long staged progression (designed to last a long time)
- Stages unlock with progress
- Persistent upgrades and growing rewards
- Feels like a long journey with regular “win” moments
- Lives are replaced by Stage number in the HUD

## Mode Switch
- On the game screen there is a tab in the top-left
- If you are in Infinite, the tab says **Campaign Mode**
- If you are in Campaign, the tab says **Infinite Mode**
- Tapping it switches instantly (each mode keeps its own feel)

## How to play from your phone
1. Upload this folder to your GitHub repo
2. Enable GitHub Pages or open `index.html` in a mobile browser / Codespaces
3. Edit files directly from the GitHub mobile site if you want
